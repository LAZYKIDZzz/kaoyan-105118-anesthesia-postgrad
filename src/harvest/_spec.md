# 105118 麻醉学专硕 · 三年录取数据采集规范（v2）

## 一、任务

为指定院校采集 **2024 / 2025 / 2026 三个招生年度**的麻醉学**专业学位硕士（专业代码 105118）**招生录取数据，
用于校正现有数据库中的单年快照错误。

## 二、最重要的三条纪律

1. **区分学位类型**：只要 105118（专硕）。10118 之外的 `100217 麻醉学`（学硕）、`1051 其他方向`、
   `1002 临床医学学硕`**一律不得计入**。若只能查到学硕数据，该项填 `null`。
2. **区分培养单位**：同一院校常有多个附属医院/临床医学院/院区分别招生，分数差可达 40 分以上。
   必须按培养单位拆分，**不得把多个院区的分数混成一个区间**。
3. **不得编造**：查不到就填 `null`，并在 `note` 里说明为什么查不到（未公布 / 只在付费库 / 名称口径不同）。
   宁可留空，不可填推测值。每个非空数字必须能在 `sources` 里找到对应 URL。

## 三、字段定义（每个招生年度一组）

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| `fs` | 复试基本分数线（进入复试的最低初试总分） | 数字；查不到填 null |
| `fs_kind` | 分数线性质 | 只能是：`国家线` / `校线` / `院线` / `自划线` / `未公布` |
| `fs_sub` | 单科线 | 形如 `"50/50/180"`（政治/外语/专业课）；未知填 null |
| `lo` | 录取（拟录取）考生**初试总分最低分** | 数字；查不到填 null |
| `hi` | 录取考生初试总分最高分 | 数字；查不到填 null |
| `avg` | 录取考生初试总分平均分 | 数字；查不到填 null。**优先用官方公布的平均分**；若需自己算，用官方名单逐个分数求平均并四舍五入取整 |
| `n` | 录取人数 | 整数；查不到填 null。**默认统计一志愿统考录取人数**，若含调剂需在 note 注明 |
| `unit` | 培养单位 | 如 `第一临床医学院`、`附属第一医院`、`瑞金医院`。若该校只有一个单位则填 `—` |
| `scope_note` | 统计口径补充 | 说明 `n` 是否含推免/调剂/5+3一体化/专项计划 |

`fs_kind` 判定：该校单独发文划定该专业复试线 → `院线`/`自划线`；执行教育部统一国家线 → `国家线`；
只公布全校/门类线（如"1051 临床医学 310 分"）→ `校线`。

## 四、来源优先级

1. **院校研究生院官网**的「硕士拟录取名单」「复试分数线公告」「复试录取工作办法」（最高可信，PDF/Excel 尤佳）
2. **院校二级学院官网**（如麻醉学院、第一临床医学院）的复试与录取公告
3. **省级教育考试院 / 研招网**公示
4. **教育部文件**（国家线）
5. 考研机构整理的汇总表（**仅作线索**）

第 5 类命中率最高但**排版常串行**（把学硕/其他专业/其他年份的数据混入），
**必须回到第 1—2 类官方名单核对"麻醉学"那一行**再采信。若无法回验，该数字标为 `null` 并在 note 记明"仅机构来源，未采信"。

## 五、检索建议

- 关键词组合：`{院校名} 麻醉学 专硕 105118 {年份} 拟录取名单`、`{院校名} {年份} 复试基本分数线 105118`、
  `{院校名} 麻醉学院 {年份} 复试录取分数`
- 优先找 **PDF 名单**，里面通常有"报考专业代码 / 初试总分 / 学习方式"三列，可直接统计。
- 微信公众号文章常完整转载官方名单，可用；但需确认确实是该年该专业。
- 若院校官网打不开，可尝试站内搜索、百度快照、或该院校对应学院官网。
