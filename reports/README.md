## 核心方法：四个指标

只看「最低分」会系统性误判。本套报告统一使用四个指标：

| 指标 | 定义 | 作用 |
| --- | --- | --- |
| **准入线** | 录取最低分 | 决定院校是否进入范围（≤ 350）；**不是目标分** |
| **中枢线** | 录取均分 | 真实竞争强度 |
| **容量** | 录取人数 | ＜3 人时，前两项指标统计意义很弱 |
| **带宽** | 均分 − 最低分 | 越大说明录取分越离散，低分越可能来自专项计划或扩招末位 |

## 重新生成

数据更新后，重跑以下脚本即可刷新网页产出（脚本从 `src/data.json` 读取数据）：

```bash
python3 src/build7_阶梯分析.py    # 生成 docs/tier350.html 与 docs/tier350-strategy.html
python3 src/build8_报告生成.py    # 生成 reports/02-分阶梯院校深度点评.md
```

逐校点评文本维护在 `src/build7_阶梯分析.py` 的 `NOTES` 字典中，报告 02 与网页共用同一份内容，不会出现两处不一致。

## 数据口径提醒

- 范围口径：录取最低分 ≤ 350；缺最低分数据时取录取均分 ≤ 350。共命中 **67 所**。
- 本项目 94 所院校中有 33 所缺最低分数据，其中 **19 所因此未纳入范围**（含徐州医科大学、新乡医学院、广西医科大学等麻醉学强校）。**被排除不等于考不上。**
- 分数数据主要来自 2025 与 2026 年。医学院校招生计划年际波动很大，报考前务必核对当年招生目录。
- 凡来源于考研机构或自媒体的信息，正文中均已标注可信度等级。
